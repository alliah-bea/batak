Download BATAK, our Batak - English translator.

1. Upon scanning the QR code, the apk file will automatically be downloaded.
2. Once downloaded, find the apk file in your device's file management system (File Manager).
3. Install the app.
   - Make sure to allow your File Manager to install apps.
   - If prompted, choose Allow and follow the instructions on your device.
   - If not, do it manually in Settings.
